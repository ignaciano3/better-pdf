# Migrating from 0.19 to 0.20

Version 0.20.0 is the **API-freeze** release. All public shape-drawing options,
ellipse radii, and document-metadata fields are now at their stable, final names.
No further renames are planned after this release.

## Breaking changes

### 1. Shape draw-options unified (`fill` / `stroke` / `strokeWidth`)

All shape-drawing methods now share a single, consistent set of option names.
If you used the old option names on `drawRectangle`, `drawEllipse`, or `drawLine`,
you must rename them.

| Method | Old option | New option |
|---|---|---|
| `drawRectangle` | `color` | `fill` |
| `drawRectangle` | `borderColor` | `stroke` |
| `drawRectangle` | `borderWidth` | `strokeWidth` |
| `drawEllipse` | `color` | `fill` |
| `drawEllipse` | `borderColor` | `stroke` |
| `drawEllipse` | `borderWidth` | `strokeWidth` |
| `drawLine` | `color` | `stroke` |
| `drawLine` | `thickness` | `strokeWidth` |

`drawSvgPath` and `drawPolygon` already used `fill`/`stroke`/`strokeWidth` and
are **unchanged**.

**Before (0.19):**

```ts
page.drawRectangle({
  x: 50, y: 50, width: 200, height: 100,
  color: rgb(0.9, 0.95, 1),
  borderColor: rgb(0.2, 0.4, 0.8),
  borderWidth: 2,
});

page.drawLine({
  start: { x: 50, y: 40 }, end: { x: 250, y: 40 },
  thickness: 1.5,
  color: rgb(0.5, 0.5, 0.5),
});
```

**After (0.20):**

```ts
page.drawRectangle({
  x: 50, y: 50, width: 200, height: 100,
  fill: rgb(0.9, 0.95, 1),
  stroke: rgb(0.2, 0.4, 0.8),
  strokeWidth: 2,
});

page.drawLine({
  start: { x: 50, y: 40 }, end: { x: 250, y: 40 },
  strokeWidth: 1.5,
  stroke: rgb(0.5, 0.5, 0.5),
});
```

### 2. `drawEllipse` radii renamed (`radiusX` / `radiusY`)

`xScale` and `yScale` are renamed to `radiusX` and `radiusY`.

**Before (0.19):**

```ts
page.drawEllipse({ x: 150, y: 200, xScale: 60, yScale: 30, color: rgb(1, 0.8, 0) });
```

**After (0.20):**

```ts
page.drawEllipse({ x: 150, y: 200, radiusX: 60, radiusY: 30, fill: rgb(1, 0.8, 0) });
```

### 3. `DocumentMetadata.modDate` → `modificationDate`

**Before (0.19):**

```ts
const meta = doc.getMetadata();
console.log(meta.modDate); // Date | undefined
```

**After (0.20):**

```ts
const meta = doc.getMetadata();
console.log(meta.modificationDate); // Date | undefined
```

### 4. Internal fields removed from the public type surface

The following fields were previously accessible but marked `@internal`. They are
now absent from the public TypeScript types. Code that accessed them will fail
under `tsc`:

- `PdfImage.bytes` (use `doc.save()` and keep your source bytes)
- `EmbeddedPdfPage.bytes`
- `PdfForm.queue` / `PdfForm.flattenQueue`
- `_fontId` / `_bytes` on internal objects

These were never part of the documented API. If you relied on them, open an issue
describing your use-case so we can provide a supported alternative.

## Non-breaking additions in 0.20

- `DrawLinkOptions`, `DrawSvgPathOptions`, and `DrawPolygonOptions` are now
  exported from both the Node (`@ignaciano3/better-pdf`) and browser
  (`@ignaciano3/better-pdf/browser`) entry points.
- `docs/STABILITY.md` documents the semver and deprecation policy.
- Two new synthetic PDF-1.5+ fixtures (larger objstm, incremental-over-xref-stream)
  are included in the test suite.

## Quick migration checklist

- [ ] Replace `color:` → `fill:` on `drawRectangle` / `drawEllipse`
- [ ] Replace `borderColor:` → `stroke:` on `drawRectangle` / `drawEllipse`
- [ ] Replace `borderWidth:` → `strokeWidth:` on `drawRectangle` / `drawEllipse`
- [ ] Replace `color:` → `stroke:` on `drawLine`
- [ ] Replace `thickness:` → `strokeWidth:` on `drawLine`
- [ ] Replace `xScale:` → `radiusX:` on `drawEllipse`
- [ ] Replace `yScale:` → `radiusY:` on `drawEllipse`
- [ ] Replace `.modDate` → `.modificationDate` on `DocumentMetadata` reads
- [ ] Remove any access to `@internal` fields (`_fontId`, `_bytes`, `.bytes` on `PdfImage`/`EmbeddedPdfPage`, `queue`/`flattenQueue` on `PdfForm`)

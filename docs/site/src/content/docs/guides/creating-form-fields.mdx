On a document created with `PdfDocument.create()`, call `doc.createForm()` to get
a chainable `FormBuilder` and declare AcroForm fields. There are six field
types — `addTextField`, `addCheckBox`, `addRadioGroup`, `addDropdown`,
`addListBox`, and `addSignatureField` — each placed by `page` index plus a
position/size in PDF points. The fields are serialized into the document on
`save()`.

<CoordinateNote>
`(x, y)` is the field's lower-left corner.
</CoordinateNote>

```ts
import { PdfDocument, PageSizes, rgb } from "@ignaciano3/better-pdf";

const doc = await PdfDocument.create();
doc.addPage(PageSizes.A4);

const form = doc
  .createForm()
  .addTextField("applicant.name", {
    page: 0, x: 56, y: 740, width: 240, height: 22,
    value: "GARCIA, IGNACIO",
    maxLength: 64,
    border: { color: rgb(0.1, 0.1, 0.4), width: 1 },
    background: rgb(0.97, 0.97, 1),
  })
  .addTextField("applicant.notes", {
    page: 0, x: 56, y: 660, width: 240, height: 60, multiline: true,
  })
  .addCheckBox("applicant.agree", {
    page: 0, x: 56, y: 620, size: 14, checked: true, required: true,
  })
  .addRadioGroup("applicant.kind", {
    selected: "primary",
    options: [
      { value: "primary", page: 0, x: 56, y: 590, size: 14 },
      { value: "dependent", page: 0, x: 120, y: 590, size: 14 },
    ],
  })
  .addDropdown("applicant.status", {
    page: 0, x: 56, y: 550, width: 160, height: 22,
    options: ["single", "married"], selected: "married",
    editable: true, // user may also type a value not in `options`
    textColor: rgb(0.1, 0.1, 0.4),
  })
  .addListBox("applicant.plan", {
    page: 0, x: 56, y: 500, width: 160, height: 48,
    options: ["basic", "plus", "premium"],
  })
  .addSignatureField("applicant.signature", {
    page: 0, x: 56, y: 440, width: 200, height: 48,
  });

console.log(form.getFieldNames()); // typed array of the declared names

const output = await doc.save();
await Bun.write("form.pdf", output);
```

:::caution[Created documents only]
`createForm()` throws on documents opened with `PdfDocument.load()`. The field
names are accumulated into the builder's type, so `getFieldNames()` is statically
typed.
:::

The result is a standard AcroForm: reload it with `PdfDocument.load(output)` and
you can fill it (`getForm().getTextField(...)`, `.getCheckBox(...).check()`, …)
and flatten it with this same library.

## Common options

Every field supports `required`, `readOnly`, `tooltip`, and the optional
appearance:

- `border` — `{ color, width? }`
- `background` — a `Color`
- `textColor` — a `Color` for the field's text/value (defaults to black)
- `align` — `"left"` (default), `"center"`, or `"right"`; horizontal
  alignment of the value
- `fontSize` — the value's font size in points (defaults to `12`)

`textColor`, `align`, and `fontSize` apply to text fields and choice fields
(dropdowns and list boxes).

Colors come from `rgb(r, g, b)` and `grayscale(v)` (each 0–1).

## Per-field options

Some options are specific to a field type:

- **Text** — `maxLength` caps the number of characters the viewer accepts;
  `multiline: true` makes the field wrap text across lines (otherwise it's a
  single line). `comb: true` renders a **comb field** — a single line split into
  `maxLength` equal cells with one character per cell (e.g. SSN or date boxes).
  Comb requires `maxLength` and is incompatible with `multiline`. `password: true`
  sets the Password flag so viewers **mask** the displayed value (dots/asterisks).
  This only changes how the value is *displayed* — it is not encryption, and it is
  independent of the value itself: `setText(...)` still stores normal text.
- **Checkbox** — `onValue` is the field's export value when checked (default
  `"Yes"`); `checked: true` ticks it initially. `checkStyle` chooses the mark
  drawn when ticked: `"check"` (default), `"cross"`, `"circle"`, `"square"`,
  `"diamond"`, or `"star"`.
- **Radio group** — `checkStyle` chooses the selected mark, same values as
  checkbox but defaulting to `"circle"`. The style applies to every option in
  the group.
- **Dropdown** — `editable: true` lets the user type a value that isn't in
  `options` (the combo box Edit flag). `addListBox` ignores it, since list boxes
  are never combo boxes.

Every value-bearing field also accepts a **default value** (`/DV`) — what a
viewer's "reset form" restores, independent of the field's initial value:
`defaultValue` (text), `defaultChecked` (checkbox), and `defaultSelected`
(radio, dropdown, list box). Omit it and no `/DV` is written. The same defaults
can be set on existing fields with `setDefaultText` / `setDefaultChecked` /
`setDefaultSelected` (see [Filling forms](/better-pdf/guides/filling-forms/)).

:::note[Field text is always Helvetica]
Field values render in Helvetica. The size (`fontSize`), color (`textColor`),
and alignment (`align`) are configurable — the font family is fixed.
:::

## Field names

Each name is the field's literal, fully-qualified name — it is **not** split
into a parent/child hierarchy on dots. `"applicant.name"` is one field called
`applicant.name`, not a `name` field nested under an `applicant` parent. Names
must be unique within the form; a duplicate throws.

## Validation

The builder validates as you add fields and throws synchronously (before
`save()`):

- **Duplicate or empty name** → `Error`.
- **`width`/`height` ≤ 0**, or a non-finite coordinate → `RangeError`.
- **`maxLength` < 0** (text) → `RangeError`.
- **`comb` without `maxLength > 0`, or `comb` with `multiline`** (text) → `RangeError`.
- **`fontSize` ≤ 0** (text or choice) → `RangeError`.
- **Empty `options`** (dropdown, list box, or radio group) → `RangeError`.
- **`selected` or `defaultSelected` not in `options`** (choice or radio) → `RangeError`.
- **`defaultValue` longer than `maxLength`** (text) → `RangeError`.
- **Duplicate radio option `value`** → `Error`.

## Reading the fields back

After reloading the saved PDF, each builder method pairs with a typed getter on
`getForm()`:

| Declared with        | Read back with    |
| -------------------- | ----------------- |
| `addTextField`       | `getTextField`    |
| `addCheckBox`        | `getCheckBox`     |
| `addRadioGroup`      | `getRadioGroup`   |
| `addDropdown`        | `getDropdown`     |
| `addListBox`         | `getListBox`      |
| `addSignatureField`  | `getSignature`    |

See the [Typed forms](/better-pdf/guides/typed-forms/) guide for how the
declared schema flows into these getters' types.

# PDF Feature Roadmap M26–M34 Implementation Plan

> **For agentic workers:** This is a **multi-milestone roadmap**, not a single executable plan. Each milestone (M26–M34) is an independent subsystem and gets its own detailed bite-sized TDD plan written at execution start (via superpowers:writing-plans), then executed via superpowers:subagent-driven-development or superpowers:executing-plans. M26 below is fully expanded as the worked template; M27–M34 are specced to actionable depth (goal, files, wire format, approach, tests, acceptance, deps, effort) — expand each to bite-sized steps when you pick it up.

**Goal:** Close the highest-impact feature gaps between better-pdf and pdf-lib, prioritizing features used by ≥1% of users and excluding legacy/dying functionality.

**Architecture:** The library has two Rust op-engines that share emit helpers: `draw.rs` (`apply_draw_ops_json` — incremental update of a loaded PDF) and `create.rs` (`create_document_json` — build from scratch). `lopdf` is the object-model backend (no font/image crates today). The TS layer (`src/`) accumulates ops as JSON + a concatenated image blob and calls one of 8 `#[wasm_bindgen]` entrypoints in `lib.rs`. **Op-variant features** (new shapes, link annotations, SVG paths, text rotation) extend the `DrawOp`/`CreateOp` serde enums + add a TS queue method — no new WASM function. **Document-level features** (metadata, merge/split, page mutation, outlines) operate on the whole document and require **new WASM entrypoints** plus a new TS save-path branch.

**Tech Stack:** Rust 2024, `lopdf` 0.41 (no default features; `wasm_js` on wasm32), `flate2`, `serde`/`serde_json`, `wasm-bindgen` 0.2; TypeScript ESM with `./forms` + `./generate` subpath exports; Bun test + `cargo test`.

## Global Constraints

- **Op-queue architecture is locked** — WASM is stateless; all state lives in the TS queue and is serialized on `save()`. Do not introduce stateful WASM handles.
- **Single package, subpath exports** (`./forms`, `./generate`) — no package split.
- **Draw features must work on BOTH loaded and created PDFs** unless a feature is inherently create-only (e.g. building an outline tree from scratch). That means most features land in `draw.rs` AND `create.rs`, reusing shared `pub(crate)` emit helpers.
- **Validate ALL ops before mutating anything** — both engines do a full validation pass first and return `Err(String)` before building. New ops follow this.
- **No CMYK, no XFA, no encryption, no JavaScript actions** — explicitly out of scope (legacy/dying or security-sensitive).
- **WinAnsi remains the default text encoding** until M27 lands custom fonts; standard-14 metrics in `font_metrics.rs` are generated by `scripts/gen-font-metrics.ts` — never hand-edit.
- **`panic = "abort"`, `-Oz` wasm-opt** — keep new deps wasm-compatible and small; gate native-only deps behind `cfg`.
- Every milestone ends green: `cargo test` + `bun test` both pass, and `pkg-web` rebuilt before bun tests on a fresh checkout (see `[[local-rust-toolchain]]`).

M28 builds the cross-document object-copy infrastructure that M29 (page mutation) and M31 (embed PDF) reuse. M30/M32/M33/M34 are independent and can be reordered freely.

```rust
//! Read/write the document Info dictionary and XMP metadata stream.
use lopdf::{Dictionary, Document, IncrementalDocument, Object};
use serde::{Deserialize, Serialize};

#[derive(Default, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct Metadata {
    #[serde(skip_serializing_if = "Option::is_none")] pub title: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")] pub author: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")] pub subject: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")] pub keywords: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")] pub creator: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")] pub producer: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")] pub creation_date: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")] pub mod_date: Option<String>,
}

fn get_str(d: &Dictionary, k: &[u8]) -> Option<String> {
    d.get(k).ok().and_then(|o| o.as_str().ok())
        .map(|b| String::from_utf8_lossy(b).into_owned())
}

pub fn read_metadata_json(data: &[u8]) -> Result<String, String> {
    let doc = Document::load_mem(data).map_err(|e| e.to_string())?;
    let mut m = Metadata::default();
    if let Ok(Object::Reference(id)) = doc.trailer.get(b"Info") {
        if let Ok(info) = doc.get_object(*id).and_then(Object::as_dict) {
            m.title = get_str(info, b"Title");
            m.author = get_str(info, b"Author");
            m.subject = get_str(info, b"Subject");
            m.keywords = get_str(info, b"Keywords");
            m.creator = get_str(info, b"Creator");
            m.producer = get_str(info, b"Producer");
            m.creation_date = get_str(info, b"CreationDate");
            m.mod_date = get_str(info, b"ModDate");
        }
    }
    serde_json::to_string(&m).map_err(|e| e.to_string())
}
```

```rust
pub fn set_metadata_json(data: &[u8], meta_json: &str) -> Result<Vec<u8>, String> {
    let meta: Metadata =
        serde_json::from_str(meta_json).map_err(|e| format!("invalid metadata: {e}"))?;
    let doc = Document::load_mem(data).map_err(|e| e.to_string())?;
    // Clone existing Info so unspecified keys survive.
    let mut info = match doc.trailer.get(b"Info") {
        Ok(Object::Reference(id)) => doc.get_object(*id).and_then(Object::as_dict).cloned().unwrap_or_default(),
        _ => Dictionary::new(),
    };
    let set = |info: &mut Dictionary, key: &str, val: &Option<String>| {
        if let Some(v) = val { info.set(key, Object::string_literal(v.as_bytes().to_vec())); }
    };
    set(&mut info, "Title", &meta.title);
    set(&mut info, "Author", &meta.author);
    set(&mut info, "Subject", &meta.subject);
    set(&mut info, "Keywords", &meta.keywords);
    set(&mut info, "Creator", &meta.creator);
    set(&mut info, "Producer", &meta.producer);
    set(&mut info, "CreationDate", &meta.creation_date);
    set(&mut info, "ModDate", &meta.mod_date);

    let mut inc = IncrementalDocument::create_from(data.to_vec(), doc);
    let info_id = inc.new_document.add_object(Object::Dictionary(info));
    inc.new_document.trailer.set("Info", Object::Reference(info_id));
    let mut out = Vec::new();
    inc.save_to(&mut out).map_err(|e| e.to_string())?;
    Ok(out)
}
```

## Milestone M27: Custom Font Embedding  *(linchpin — write detailed plan before starting)*

**Goal:** Embed TrueType/OpenType fonts with glyph subsetting and full Unicode text, replacing the standard-14-only limitation. Enables non-Latin scripts, brand fonts, and emoji-free CJK.

**Why it's the linchpin:** today text is encoded as WinAnsi bytes (`encode_winansi` in `appearance.rs`) and drawn with a `Type1` `font_dict` (`draw.rs:105`). Unicode requires a **Type0 / CIDFontType2** composite font: text encoded as 2-byte glyph IDs, a `CIDToGIDMap`, embedded subset font program (`FontFile2`), `/W` width array, and a `ToUnicode` CMap for copy/paste & search. This changes the text emit path, `measure_text`, and form-field appearance generation — so it lands before other text features.

**Files:**
- Add dep: `ttf-parser` (wasm-friendly, no_std-capable) for glyph metrics + cmap; evaluate a subsetter (`subsetter` crate, or hand-roll glyf/loca subsetting). Gate size impact — measure `pkg-web` delta.
- Create: `crates/core/src/fonts/mod.rs` (parse, subset, build CID font dicts, ToUnicode), `crates/core/src/fonts/subset.rs`, `crates/core/src/fonts/cmap.rs`.
- Modify: `draw.rs` + `create.rs` Text op handling — when font is an embedded-font key, emit glyph-ID hex strings (`<00A4...> Tj`) instead of WinAnsi literals; register the embedded font dict instead of `font_dict`.
- Modify: `lib.rs` — `measure_text` must accept embedded fonts; new `embed_font(data) -> String` returning `{unitsPerEm, ascent, descent, glyphCount}` info, and the font bytes flow through a blob like images.
- Modify: TS `src/generate/font.ts`, `draw-queue.ts` (font blob channel parallel to image blob), `document.ts` `embedFont(bytes, {subset?:boolean})`.

**Wire format:** add a font blob (concat like images) and a `fontOffset`/`fontLength`/`subset` to Text ops that use an embedded font; font referenced by an index assigned at queue time.

**Approach (phased — split into M27a/M27b when writing the detailed plan):**
- **M27a — embed full font, no subset, WinAnsi/cmap-Latin path:** prove `FontFile2` embedding + a simple TrueType font dict renders text in Acrobat/Chrome/pdf.js. Quick confidence win.
- **M27b — Type0/CID + subsetting + ToUnicode:** the real deliverable. Subset to used glyphs, build `CIDFontType2` + `/W`, `CIDToGIDMap=Identity`, `Encoding=Identity-H`, `ToUnicode` CMap.

**Test strategy:** Rust unit tests parse a fixture TTF (add a small open-licensed font, e.g. a subset of Noto Sans), assert glyph width lookup matches known AFM-free values, assert subset font program is smaller than original and still parses via `ttf-parser`. TS test: embed font, draw "Héllo → 日本語", save, reload, assert the content stream uses hex glyph strings and the font dict is `Type0`. Verify visually with the `verify` skill / pdf.js render.

**Acceptance:** `doc.embedFont(bytes)` returns a font handle usable in `drawText`; Unicode text renders; subset output materially smaller; text is selectable/searchable (ToUnicode present). `measure_text`/`widthOfTextAtSize` correct for embedded fonts.

**Deps/risks:** subsetting is the hard part and the main `pkg-web` size risk — measure and, if needed, make subsetting opt-in (`{subset:false}` embeds the full font). Keep standard-14 path untouched as the default.

## Milestone M28: Page Operations (merge / copy / insert / remove / reorder / split)

**Goal:** Combine and rearrange pages across documents — the `copyPages`/merge use case that is one of pdf-lib's most-used features.

**Files:**
- Create: `crates/core/src/pageops.rs`.
- Modify: `lib.rs` — new `manipulate_pages(docs_blob, ops_json) -> Vec<u8>` taking a concatenated blob of N source PDFs (offset/length per doc, like images) and a plan of operations.
- Modify: TS `document.ts` — static `PdfDocument.merge(docs: Uint8Array[])`, `doc.copyPages(src, indices)`, `doc.removePage(i)`, `doc.insertPage(i, …)`, `doc.movePage(from, to)`, and a `splitPages()` returning multiple `Uint8Array`s.

**Wire format:**
```json
{"ops":[{"op":"copyPage","srcDoc":0,"srcIndex":2},{"op":"copyPage","srcDoc":1,"srcIndex":0}]}
```
Output page order = op order. `srcDoc` indexes into the docs blob.

**Approach:** lopdf can load each source `Document`; build a fresh output `Document`, deep-copy each requested page's object graph (page dict + Contents + Resources + referenced fonts/XObjects), remapping object IDs to avoid collisions. This object-remapping helper is the **reusable core** that M29 and M31 depend on — design it as `pub(crate) fn import_object_tree(dst, src, id) -> ObjectId` with an ID-remap `HashMap`. Inherited page attributes (MediaBox/Resources from `/Pages`) must be resolved onto the copied page so it stands alone.

**Test strategy:** merge two fixtures, assert `get_pages().len()` equals the sum; assert a copied page's text/Resources survive (decompress Contents, grep for a known string); remove/reorder change the page count/order; split yields N single-page valid PDFs that each reload. TS parity tests.

**Acceptance:** merge, copy-from-other-doc, insert blank, remove, reorder, and split all work and produce valid reloadable PDFs. AcroForm field handling on copied pages: at minimum don't corrupt; ideally carry widget annotations (document the limitation if fields are dropped).

**Deps:** none. **Effort:** L (object-graph remapping is the crux).

## Milestone M29: Page Mutation (rotate / resize existing pages)

**Goal:** Mutate existing-page `/Rotate` and `/MediaBox` (and `/CropBox`) — `setRotation`, `setSize`, `scale`.

**Files:** fold into `pageops.rs` + `manipulate_pages` from M28 with ops `{"op":"setRotation","page":i,"degrees":90}` and `{"op":"setMediaBox","page":i,"box":[x0,y0,x1,y1]}`. TS: `page.setRotation(deg)`, `page.setSize(w,h)`, `page.setMediaBox(...)`.

**Approach:** incremental update — clone the page dict into the new document, set `/Rotate` (must be a multiple of 90; validate) or `/MediaBox`. Reuse `dict_mut`/`opt_clone_object_to_new_document` exactly as `draw.rs` does.

**Test strategy:** rotate a page 90°, reload, assert `read_pages` reports `rotation:90`; resize, assert new MediaBox. Validate non-multiple-of-90 errors.

**Acceptance:** rotation and size mutations persist and are reported by `read_pages`. **Deps:** M28 (shares `manipulate_pages` + clone infra). **Effort:** S.

## Milestone M30: Image Transparency (PNG alpha → SMask)

**Goal:** Preserve PNG alpha as a soft mask instead of flattening RGBA→RGB, so logos/watermarks with transparency render correctly.

**Files:** Modify `appearance.rs` image path (`signature_image` / `build_signature_image_xobject`). Likely add a real PNG decoder dep (`png` crate, or extend the existing minimal decoder) that retains the alpha channel.

**Approach:** split decoded RGBA into an RGB image XObject + a grayscale `/SMask` image XObject; set `/SMask` on the main image dict. JPEG path unchanged. Keep the current "no palette/interlace" constraints or lift them if the new decoder handles them (document either way).

**Test strategy:** embed a known semi-transparent PNG, assert the resulting image XObject has an `/SMask` reference and the SMask stream is grayscale with the expected dimensions. Visual check via `verify`.

**Acceptance:** transparent PNGs composite over page content; opaque PNGs unchanged; no regression in existing image tests. **Deps:** none. **Effort:** M (dep + size impact to measure).

## Milestone M31: Embed PDF Pages as XObject (`embedPdf` / `drawPage`)

**Goal:** Draw an existing PDF page as a Form XObject onto another page — watermarks, letterhead overlays, N-up.

**Files:** Modify `appearance.rs`/`draw.rs`/`create.rs` to add an `op:"page"` draw op referencing an embedded source page; new `lib.rs` info path. Reuse M28's `import_object_tree`.

**Approach:** convert a source page into a Form XObject (wrap its content stream + resources, set `/BBox` from its MediaBox, `/Matrix` for scale/position), import its resource graph via M28's remapper, then emit `q cm /BPp{n} Do Q` just like the image op (`emit_image_op` is the template).

**Test strategy:** embed page 0 of fixture A as an XObject on a new page in doc B; assert the output references a Form XObject (`/Subtype /Form`) and `/BPp0 Do` appears in the content stream; reload validity.

**Acceptance:** a source page renders at a given position/scale on a target page (loaded or created). **Deps:** M28. **Effort:** L.

## Milestone M32: Link Annotations (URI + internal GoTo)

**Goal:** Clickable hyperlinks (external URI) and internal jumps (GoTo page/destination) — common in reports, invoices, TOCs.

**Files:** add `op:"link"` to `DrawOp`/`CreateOp` enums (`draw.rs`/`create.rs`); the handler appends a `/Annot /Subtype /Link` to the page's `/Annots` (create.rs already builds `/Annots` for widgets — reuse that path; draw.rs must clone the page and append). TS: `page.drawLink({x,y,width,height, url})` and `{ ..., goToPage }`.

**Wire format:** `{"op":"link","page":i,"rect":[x0,y0,x1,y1],"uri":"https://…"}` or `{"…","goToPage":3}`.

**Approach:** URI link → `/A << /S /URI /URI (…) >>`; GoTo → `/Dest [page /XYZ left top zoom]` or a named destination. Set `/Border [0 0 0]` to suppress the visible box by default. In `draw.rs`, append to `/Annots` using the same clone-and-mutate pattern as content streams.

**Test strategy:** add a URI link, reload, assert the page `/Annots` contains a `/Link` with the URI; add a GoTo, assert `/Dest` targets the right page object. 

**Acceptance:** URI and internal links present and valid on loaded and created PDFs. **Deps:** none. **Effort:** M.

## Milestone M33: SVG Path / Bezier / Polygon Drawing

**Goal:** Arbitrary vector paths — `drawSvgPath(d)`, `drawBezier`, `drawPolygon` — for icons, charts, logos.

**Files:** add `op:"path"` to both enums + a `crate::draw::emit_path` helper (sibling of `emit_line`/`emit_ellipse`); an SVG-path-`d`-string parser in Rust (or parse in TS to primitive segments and send those — **prefer TS parsing** to keep the wasm small and the Rust op a simple list of move/line/cubic/close segments).

**Wire format:** `{"op":"path","page":i,"segments":[{"t":"m","x":..,"y":..},{"t":"c","x1":..,...},{"t":"l",...},{"t":"z"}],"fill":[r,g,b],"stroke":[r,g,b],"strokeWidth":w,"opacity":o}`.

**Approach:** map segments to PDF path operators (`m`/`l`/`c`/`h`) then a paint op via the existing `paint_op(has_fill, has_stroke)` (`draw.rs:171`). Reuse `extgstate_dict`/`register_extgstate` for opacity. SVG y-axis is top-down vs PDF bottom-up — document that callers pass PDF coordinates, or provide a `flipY` helper in TS.

**Test strategy:** draw a triangle (3 lines + close + fill), assert content has `m`,`l`,`h`,`f`; draw a cubic, assert `c`; fill+stroke uses `B`.

**Acceptance:** polygons, beziers, and parsed SVG `d` strings render with fill/stroke/opacity. **Deps:** none. **Effort:** M.

## Milestone M34: Text Rotation + Opacity, and Outlines/Bookmarks

Two independent small features bundled (split if either grows).

**M34a — Text rotation + opacity:**
- **Files:** extend the `Text` variant in `DrawOp`/`CreateOp` with optional `rotate` (degrees) and `opacity`; update `emit_text_block` (`draw.rs:118`) to wrap the block in `q … Q`, apply a rotation matrix via `cm` before `BT`, and reference an ExtGState for opacity (reuse `extgstate_dict`).
- **Test:** rotated watermark text emits a `cm` matrix and `/BPG{n} gs`; assert angle math (cos/sin) in the matrix.
- **Acceptance:** rotated, translucent watermark text on loaded + created PDFs.

**M34b — Outlines/bookmarks:**
- **Files:** new `crates/core/src/outline.rs`; create-mode primarily (build `/Outlines` tree in catalog), plus an incremental `set_outline(data, json)` WASM fn for loaded PDFs. TS: `doc.setOutline([{title, page, children?}])`.
- **Approach:** build `/Outlines` dict with `/First`/`/Last`/`/Count` and per-item `/Title`/`/Parent`/`/Dest`/`/Next`/`/Prev`; reference from catalog. Nested children supported.
- **Test:** set a 2-level outline, reload, assert catalog `/Outlines` exists with the right `/Count` and a leaf `/Dest` targets the right page.
- **Acceptance:** named, nested bookmarks navigate to pages in a viewer.
- **Deps:** M34b is independent; text rotation benefits from M27 fonts for non-Latin watermarks but doesn't require it. **Effort:** M total.
